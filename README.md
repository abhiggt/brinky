# Brinky: Blink & Drink breaks

Brinky is a free Chrome extension for eye breaks, water, movement and posture. It has three modes (Recommended, Work mode and SuperBrink), waits for a natural pause and stays quiet during calls.

**Website and download:** https://abhiggt.github.io/brinky/

## Install
1. [Download brinky.zip](docs/download/brinky.zip) and unzip it into a folder you'll keep, like `Documents/Brinky`.
2. Open `chrome://extensions` (in Edge, `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and choose the Brinky folder. Pin Brinky from the puzzle-piece menu.

Brinky isn't in the Chrome Web Store yet, which is why it's installed from a folder.

## What's in this repository
| Folder | What it is |

| `docs/` | The website, served by GitHub Pages: one page, `index.html`, with the blink.drink. story at `#blink-drink`. `docs/download/brinky.zip` is the optimised build people install. |
